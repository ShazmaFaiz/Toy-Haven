# Toy Haven — COMP40053 Assignment 3

A responsive front-end toy and collectibles store built using **HTML, CSS and JavaScript only**.

## Included pages
1. Home — rotating promotional hero, featured products, Product of the Day, newsletter.
2. Products — JavaScript product data, search, category filters, product cards, modal details, cart/wishlist actions.
3. Shopping Cart — persistent localStorage cart, quantity controls, subtotals, total and clear-cart action.
4. Checkout — validated form, Card/Cash on Delivery simulation, order summary, success animation, order history in localStorage.
5. Wishlist / Collection — save products and set Interested / Owned / Not Interested.
6. Feedback & Support — validated feedback form stored in localStorage and JavaScript FAQ accordion.

## Requirements implemented
- Responsive/mobile-first layout with Flexbox and CSS Grid
- Animated hamburger navigation
- Auto-rotating hero promotions
- Product of the Day based on the current date
- Product filtering and name search
- Product details modal
- Dynamic cart and wishlist
- localStorage for cart, wishlist, newsletter, feedback and order history
- Form validation and user feedback messages
- CSS hover effects, transitions and scroll reveal animations
- Semantic HTML, labels, ARIA attributes and reduced-motion support
- Favicon and installable PWA manifest + service worker
- Reusable JavaScript functions shared across pages

## Important before submission
The assignment also requires GitHub Pages hosting and evidence from W3C HTML/CSS validation, WAVE, Lighthouse (desktop + mobile), responsiveness testing and wireframes. Those external services require the final hosted site/browser, so use `docs/Test-Cases.md` as the test record and complete the live-service checks before submitting.

## Run locally
Open `index.html` for basic browsing. For full PWA/service-worker testing, use a local server (for example VS Code Live Server) rather than opening files directly.
